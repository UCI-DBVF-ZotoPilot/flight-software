# members

This folder is a **practice run for pull requests**.

## Your Task
Add a file named 'yourname.md' with:
- Your name
- Your role (Software or Embedded)
- One thing you want to work on this year

## Steps
1. **Clone the repo** (First time only):
   ```bash
   git clone https://github.com/UCI-DBVF-ZotoPilot/flight-software.git
   cd flight-software
   ```
2. **Make a branch:**
   ```bash
   git checkout -b yourname/intro
   ```
3. **Add your file:** Create 'members/yourname.md'.
4. **Commit and push:**
   ```bash
   git add members/yourname.md
   git commit -m "Add yourname to members"
   git push -u origin yourname/intro
   ```
5. **Open a pull request:** On GitHub, click **Compare & Pull Request**. The description box is already filled in with our PR template. Fill in "What changed" and delete anything that doesn't apply.
6. **Ask for a review** and respond to any comments by pushing to the same branch.
7. **Merge** once it's approved, using **Squash and Merge**.

## What this Tests
- You can clone the repo and push a branch
- You **can't** push directly to 'main'
- You can open a PR, use the template and get a review.

If any step fails, ask for help. That's what this test is for.
