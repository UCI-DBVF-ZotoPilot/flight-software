# flight-software
Autonomous mission code for **ZotoPilot**, UCI's team in the 2026–2027 VFS Design-Build-Vertical Flight competition.

This code runs on the drone's Jetson and tells the Cube Orange (ArduPilot) what to do over MAVLink.

## What to do (tentative):

1. Pull the latest `main`.
2. Make a branch for your task: `yourname/short-topic`.
3. Commit with clear messages ("Add takeoff script", not "stuff").
4. Push and open a pull request into `main`.
5. Get one approval, then **Squash and merge**.

**Never push directly to `main`. One branch per task.**
